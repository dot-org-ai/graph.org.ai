# AI Models Domain

A comprehensive registry of AI models available through various providers, including their capabilities, pricing, and technical specifications.

## Entity Types

Browse AI model data:

- **[Models](/model/Model)** - 306 AI models from various providers
- **Model Families** - Groups of related models (e.g., GPT series, Claude series)
- **Providers** - Model hosting services and API providers

## Model Categories

Models are categorized by type and capability:

- **Language Models** - Text generation and understanding
  - Chat models (conversational AI)
  - Completion models (text generation)
  - Embedding models (vector representations)

- **Multimodal Models** - Multiple input/output types
  - Vision-language models
  - Audio-text models
  - Code generation models

- **Specialized Models** - Domain-specific capabilities
  - Code models (programming assistance)
  - Math models (mathematical reasoning)
  - Translation models (language translation)

## Model Attributes

Each model entry includes:

- **Name & Provider** - Model identifier and hosting service
- **Context Window** - Maximum input tokens
- **Pricing** - Cost per token (input/output)
- **Capabilities** - Supported features (function calling, vision, etc.)
- **Performance** - Benchmarks and specifications
