# Schema.org Domain

Schema.org is a collaborative project providing schemas (structured data markup) that webmasters can use to markup their pages in ways recognized by major search providers.

## Entity Types

Browse Schema.org vocabulary:

- **[Types](/schema.org/Type)** - Classes and entity types (e.g., Person, Organization, Event)
- **[Properties](/schema.org/Property)** - Attributes that can be used with types
- **[Data Types](/schema.org/DataType)** - Primitive data types (Text, Number, Date, etc.)
- **[Enumerations](/schema.org/Enumeration)** - Fixed sets of values

## Schema Hierarchy

Schema.org types are organized in an inheritance hierarchy with `Thing` as the root:

```
Thing
├── Action
├── CreativeWork
│   ├── Article
│   ├── Book
│   └── SoftwareApplication
├── Event
├── Organization
├── Person
├── Place
└── Product
```

## Use Cases

- **SEO** - Rich snippets and enhanced search results
- **Knowledge Graphs** - Structured data for AI systems
- **Data Integration** - Standard vocabulary for data exchange
- **Web APIs** - Consistent data models

## Data Source

Schema vocabulary comes from [schema.org](https://schema.org/), a community effort backed by Google, Microsoft, Yahoo, and Yandex.
