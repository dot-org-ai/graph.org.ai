## Core Nouns (Entities)

### People
- **Visitor** - Anonymous traffic
- **User** - Signed up, not paying
- **Customer** - Paying subscriber
- **Advocate** - Promoter, referrer
- **Champion** - Power user, internal advocate

### Financial
- **Subscription** - Recurring payment agreement
- **Invoice** - Payment request
- **Payment** - Transaction
- **Refund** - Return of payment
- **Credit** - Account balance
- **MRR** - Monthly Recurring Revenue
- **ARR** - Annual Recurring Revenue
- **LTV** - Lifetime Value
- **CAC** - Customer Acquisition Cost

### Product
- **Feature** - Product capability
- **Integration** - Connection to external system
- **API** - Programmatic interface
- **Workspace** - Customer environment
- **Project** - Customer work container
- **Asset** - Customer-created resource

### Marketing
- **Campaign** - Marketing initiative
- **Lead** - Potential customer contact
- **Content** - Blog, guide, video
- **SEO** - Search optimization
- **Ad** - Paid promotion
- **Email** - Communication message
- **Webinar** - Educational event

## Core Processes

### Acquisition Process

```
1. Visitor Discovery
   - SEO content ranking
   - Paid ad click
   - Social media post
   - Referral link

2. Landing Page
   - Value proposition
   - Social proof
   - Clear CTA
   - Low friction

3. Signup
   - Email capture
   - Password creation
   - Email verification
   - Welcome email
```

### Activation Process

```
1. Onboarding
   - Welcome screen
   - Setup wizard
   - First action prompt
   - Quick win

2. Aha Moment
   - Core value delivery
   - Success confirmation
   - Next steps

3. Habit Formation
   - Regular usage prompts
   - Email nudges
   - In-app notifications
```

### Monetization Process

```
1. Trial Start
   - Feature access
   - Usage tracking
   - Engagement monitoring

2. Trial Nurture
   - Usage tips
   - Success stories
   - Upgrade prompts

3. Conversion
   - Upgrade CTA
   - Plan selection
   - Payment collection
   - Invoice generation
```

### Retention Process

```
1. Usage Monitoring
   - Activity tracking
   - Health scoring
   - Churn prediction

2. Engagement
   - Feature adoption
   - Regular check-ins
   - Success milestones

3. Renewal
   - Renewal reminder
   - Payment processing
   - Subscription continuation
```

### Expansion Process

```
1. Upsell Opportunities
   - Usage limits approaching
   - Feature requests
   - Team growth

2. Expansion Offer
   - Upgrade recommendation
   - Additional features
   - Higher tier benefits

3. Expansion Close
   - Plan upgrade
   - Payment adjustment
   - MRR expansion
```

## OKRs Example

### Objective: Achieve Product-Market Fit

**Key Results:**
- Reach 100 paying customers
- Achieve NPS score of 50+
- Reduce churn to <5% monthly
- Reach 40% activation rate

### Objective: Scale Acquisition

**Key Results:**
- Grow MRR 20% month-over-month
- Reduce CAC by 30%
- Achieve LTV/CAC ratio of 3+
- Generate 10,000 monthly visitors

### Objective: Improve Retention

**Key Results:**
- Increase NRR to 110%
- Reduce logo churn to <3%
- Achieve 90-day retention of 70%
- Increase feature adoption to 60%
