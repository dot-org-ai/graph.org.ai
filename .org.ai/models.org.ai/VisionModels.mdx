# Vision Models

Vision models enable machines to perceive, understand, and generate visual information with increasing sophistication. From image classification to object detection, semantic segmentation, and generative tasks, vision models power applications across healthcare, autonomous systems, content creation, and visual analytics.

## Overview

Vision models process visual information through convolutional neural networks and transformer-based architectures, learning to extract meaningful features from pixels and video frames. Modern approaches achieve human-level performance on many visual tasks while enabling entirely new applications like image generation and visual question answering.

## Image Classification Models

### Foundational Architectures

**ImageNet-era Models**
- **ResNet (Residual Networks)**: Deep learning breakthrough
  - Introduced residual connections for training deep networks
  - Pre-trained on ImageNet: 1000 classes
  - Strong feature extraction for downstream tasks
  - Efficient inference and small model variants

- **EfficientNet**: Scaling and efficiency focus
  - Balance of accuracy and computational efficiency
  - Mobile-friendly variants available
  - State-of-the-art accuracy-efficiency trade-offs
  - Systematic scaling approach

- **Vision Transformer (ViT)**: Transformer architecture for vision
  - Patches treated as tokens
  - Self-attention for spatial relationships
  - Superior scaling properties
  - Transfer learning effectiveness

### Modern Classification Models

**Google Vision Models**
- **EfficientNet-V2**: Improved efficiency and accuracy
  - Faster training and inference
  - Better robustness and generalization
  - Competitive ImageNet accuracy
  - Deployment-friendly

- **MobileViT**: Mobile Vision Transformer
  - Efficient transformer for mobile
  - High accuracy at low compute
  - Cross-layer attention
  - Edge device suitable

**Facebook/Meta Dino V2**
- Advanced self-supervised learning
- Powerful zero-shot classification
- Transfer learning strength
- Minimal dataset size requirements

### Multimodal Vision-Language Models

**CLIP (Contrastive Language-Image Pre-training)**
- Image and text joint embeddings
- Zero-shot image classification via text
- Incredible generalization to unseen classes
- Foundation for many downstream tasks

**BLIP and BLIP-2**
- Vision-language understanding and generation
- Visual question answering (VQA)
- Image captioning and description
- Improved alignment over CLIP
