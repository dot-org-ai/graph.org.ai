# Model Architectures

Model architectures provide the foundational designs for neural networks that power modern AI. From attention-based transformers to convolutional networks and mixture of experts, these architectures enable the remarkable capabilities of contemporary models.

## Overview

Neural network architectures define how information flows through layers of computation. Successful architectures balance computational efficiency, representational capacity, and training stability. Modern deep learning is built on a relatively small number of core architectural innovations that have proven effective across diverse domains.

## Transformer Architecture

### Foundation and Evolution

**The Original Transformer (2017)**
- "Attention Is All You Need" paper
- Self-attention as core mechanism
- Eliminated recurrence in sequence modeling
- Parallel training across sequence
- Foundation for modern NLP and beyond

**Key Components**
- Multi-head self-attention layers
- Position-wise feed-forward networks
- Positional encoding for sequence order
- Layer normalization for training stability
- Residual connections for gradient flow

**Encoder-Decoder Architecture**
- Encoder processes input sequence
- Decoder generates output sequence
- Cross-attention between encoder and decoder
- Autoregressive generation
- Sequence-to-sequence tasks

### Attention Mechanisms

**Self-Attention and Multi-Head Attention**
- Query, key, value projections
- Multiple representation subspaces
- Parallel attention computation
- Information combination from multiple perspectives
- Interpretability and visualization

**Scaled Dot-Product Attention**
- Query-key dot product similarity
- Temperature scaling for stability
- Softmax normalization
- Value-weighted combination
- Foundational attention computation

**Cross-Attention**
- Attend to different sequence
- Input-output alignment
- Conditional generation
- Decoder-encoder interaction
- Multi-modal fusion

### Variants and Improvements

**Vision Transformer (ViT)**
- Apply transformer to image patches
- Image classification at scale
- Strong transfer learning
- Efficient scaling properties
- Foundation for vision models

**BERT and Masked Language Modeling**
- Bidirectional encoder representation
- Masked token prediction
- Unsupervised pre-training
- Strong transfer learning
- NLP foundation model

**GPT and Causal Language Modeling**
- Decoder-only architecture
- Autoregressive generation
- Scalable pre-training
- Next-token prediction
- Foundation for LLMs

**T5 and Unified Sequence-to-Sequence**
- Text-to-text framework
- Unified architecture for diverse tasks
- Shared transformer architecture
- Task specification via prefixes
- Flexible task adaptation

### Efficient Attention Mechanisms

**Linear Attention**
- Reduce quadratic complexity
- Linear complexity attention
- Approximate similarity
- Kernel-based approaches
- Longer sequence capability

**Sparse Attention**
- Attend only to subset of positions
- Block-sparse patterns
- Local window attention
- Structured sparsity
- Computational savings

**Multi-Query and Grouped Query Attention**
- Reduce key-value cache size
- Shared attention heads
- Faster decoding
- Maintained quality
- Practical improvements

**Flash Attention and Optimizations**
- GPU-efficient implementation
- Reduce memory bandwidth
- Kernel fusion
- Dramatic speedup

## Recurrent Neural Networks (RNNs)

### Core RNN Variants

**Long Short-Term Memory (LSTM)**
- Gates for information flow
- Gradient flow preservation
- Long-range dependency learning
- Forget, input, and output gates
- Foundational sequence model

**Gated Recurrent Unit (GRU)**
- Simplified LSTM variant
- Fewer parameters
- Similar performance
- Faster training
- Practical alternative

**Bidirectional RNNs**
- Process sequence forwards and backwards
- Full context utilization
- Better performance than unidirectional
- Offline processing only
- Standard practice for NLP

### RNN Applications and Variants

**Sequence-to-Sequence Models**
- Encoder RNN processes input
- Decoder RNN generates output
- Attention mechanism over encoder
- Machine translation
- Abstractive summarization

**Attention Mechanisms with RNNs**
- Dynamic context vector
- Improved long-range dependencies
- Interpretable alignment
- Bridge to transformer architecture
- Practical improvements

### Limitations and Transition

**RNN Limitations**
- Sequential processing prevents parallelization
- Gradient vanishing/exploding
- Long-range dependencies challenging
- Slower training than CNNs/Transformers
- Historical importance, limited modern use

**Transition to Transformers**
- Transformer advantages for NLP
- Parallelizable training
- Stronger long-range modeling
- Better scaling properties
- Modern standard

## Normalization Techniques

### Layer Normalization

**Layer Norm Properties**
- Normalize across features (not batch)
- Stable training dynamics
- Transformer standard
- Invariant to absolute magnitudes
- Essential for stability

**Variants**
- Pre-normalization (before sublayer)
- Post-normalization (after sublayer)
- Residual connections interaction
- Training and inference implications
- Empirical performance differences

### Batch Normalization

**Batch Norm in Training**
- Normalize across batch dimension
- Reduce internal covariate shift
- Smooths loss landscape
- Allows higher learning rates
- CNN standard

**Batch Norm Challenges**
- Different behavior at train/test
- Batch size sensitivity
- Problematic for small batches
- Sequential model issues
- Inference time considerations

### Group and Instance Normalization

**Group Norm**
- Normalize across groups of channels
- Batch size independent
- Vision transformer adoption
- Parameter-free
- Training stability

**Instance Norm**
- Per-instance normalization
- Style transfer and generative models
- Strong across domain shifts
- Limited batch awareness
- Specialized applications
