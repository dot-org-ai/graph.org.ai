# O*NET Work Contexts

Reference documentation for O*NET Work Context codes.

## Overview

Work Contexts describe the physical and social factors that influence the nature of work. This subdirectory provides reference mappings to the official O*NET work context codes.

**Note**: This is reference data. The primary context ontology lives at [context.org.ai](https://context.org.ai).

## Cross-References

Context entities in [context.org.ai](https://context.org.ai) reference O*NET codes via the `sameAs` property:

```typescript
{
  "@type": "Context",
  "@id": "https://context.org.ai/Context/4C1a1",
  "name": "Indoors, Environmentally Controlled",
  "sameAs": "https://onet.org.ai/WorkContexts/4C1a1"
}
```
