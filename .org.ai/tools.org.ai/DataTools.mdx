# Data Tools

ETL, data visualization, querying, transformation, and analytics tools for data processing and business intelligence.

## Overview

Data tools enable organizations to collect, process, transform, visualize, and analyze data at scale. These tools form the modern data stack (MDS), enabling self-service analytics, real-time dashboards, and data-driven decision making.

## ETL & Workflow Orchestration

### Apache Airflow

Python-based workflow orchestration platform for building, scheduling, and monitoring data pipelines.

**Key Concepts:**

```python
from airflow import DAG
from airflow.operators.python import PythonOperator
from datetime import datetime

def extract_data():
    # Extract data from source
    pass

def transform_data():
    # Transform and clean data
    pass

def load_data():
    # Load to destination
    pass

dag = DAG(
    'etl_pipeline',
    start_date=datetime(2024, 1, 1),
    schedule_interval='@daily'
)

extract = PythonOperator(
    task_id='extract',
    python_callable=extract_data,
    dag=dag
)

transform = PythonOperator(
    task_id='transform',
    python_callable=transform_data,
    dag=dag
)

load = PythonOperator(
    task_id='load',
    python_callable=load_data,
    dag=dag
)

extract >> transform >> load
```

**Features:**
- Directed Acyclic Graph (DAG) definitions
- Operator library (BashOperator, PythonOperator, etc.)
- Backfill and rerun capabilities
- Monitoring and alerting
- Scaling with Kubernetes executor

### dbt (Data Build Tool)

SQL-first data transformation tool for building, testing, and documenting analytics.

```sql
-- models/staging/stg_orders.sql
with source as (
    select * from {{ source('raw', 'orders') }}
),
transformed as (
    select
        order_id,
        customer_id,
        order_date,
        total_amount,
        cast(order_date as date) as order_day
    from source
    where order_id is not null
)
select * from transformed
```

**Features:**
- Version control for analytics code
- Testing and data validation
- Documentation generation
- Lineage and dependency management
- Incremental models for efficiency

### Prefect

Modern data workflow orchestration with improved developer experience:

```python
from prefect import flow, task

@task
def fetch_data(url: str):
    return requests.get(url).json()

@task
def process_data(data: dict):
    return {k: v * 2 for k, v in data.items()}

@flow
def analytics_pipeline(url: str):
    data = fetch_data(url)
    processed = process_data(data)
    return processed

analytics_pipeline("https://api.example.com/data")
```

## Data Transformation & Processing

### Apache Spark

Unified analytics engine for big data processing:

```python
from pyspark.sql import SparkSession

spark = SparkSession.builder.appName("DataProcessing").getOrCreate()

# Read data
df = spark.read.csv("data.csv", header=True)

# Transform
transformed = df.filter(df.age > 18) \
    .groupBy("city") \
    .agg({"salary": "avg"})

# Write results
transformed.write.parquet("output/")
```

**Capabilities:**
- Distributed SQL queries
- Streaming data processing
- Machine learning pipeline
- Partition pruning for performance
- Support for multiple file formats

### Pandas (Python)

Popular data manipulation library for smaller datasets:

```python
import pandas as pd

# Read data
df = pd.read_csv("data.csv")

# Transform
df['age_group'] = pd.cut(df['age'], bins=[0, 18, 65, 100])
df['new_column'] = df['col1'] * df['col2']

# Aggregate
summary = df.groupby('category').agg({
    'sales': 'sum',
    'quantity': 'mean'
})

# Write
df.to_parquet("output.parquet")
```

## Data Querying & Analytics

### ClickHouse

Fast, open-source columnar database for OLAP workloads:

```sql
-- Create table
CREATE TABLE events (
    timestamp DateTime,
    user_id UInt32,
    event_type String,
    value Float32
) ENGINE = MergeTree()
ORDER BY (timestamp, user_id)

-- Insert data
INSERT INTO events VALUES
('2024-01-01 10:00:00', 1, 'click', 1.0)

-- Query
SELECT
    user_id,
    event_type,
    count() as event_count,
    avg(value) as avg_value
FROM events
WHERE timestamp >= '2024-01-01'
GROUP BY user_id, event_type
ORDER BY event_count DESC
```

**Advantages:**
- 100x faster than traditional OLAP databases
- Columnar storage for analytical queries
- Compression up to 87%
- Horizontal scaling
- Real-time data ingestion

### BigQuery

Google Cloud's serverless data warehouse:

```sql
-- Create dataset and table
CREATE SCHEMA `project.analytics`

CREATE TABLE `project.analytics.events` (
    timestamp TIMESTAMP,
    user_id INT64,
    event_type STRING,
    value FLOAT64
)

-- Query across tables
SELECT
    DATE(timestamp) as date,
    COUNT(*) as total_events,
    COUNT(DISTINCT user_id) as unique_users
FROM `project.analytics.events`
WHERE timestamp >= TIMESTAMP('2024-01-01')
GROUP BY date
ORDER BY date DESC
```

**Features:**
- Serverless scaling
- Multi-cloud support
- Built-in machine learning
- Strong integration with GCP services
- BI Engine for acceleration

## Data Pipeline Patterns

### Lambda Architecture

```
        Raw Data
           |
        +--+--+
        |  |  |
      Batch | Speed
      Layer | Layer
        |  |  |
        +--+--+
           |
      Serving Layer
           |
        Analytics
```

**Implementation:**
- Batch: Spark, Airflow, dbt
- Speed: Kafka, Flink
- Serving: ClickHouse, Druid

### Kappa Architecture

```
    Raw Data → Stream Processing → Serving Layer → Analytics
       ↑                                              ↓
       +--- Reprocessing (state rebuild) -----------+
```

**Benefits:**
- Simpler architecture
- Single codebase for transformations
- Real-time results
- Easier to debug

## Best Practices

### Pipeline Development

1. **Modular Design**: Break pipelines into small, testable tasks
2. **Error Handling**: Implement retry logic and dead-letter queues
3. **Monitoring**: Track data quality and pipeline health
4. **Documentation**: Document data lineage and transformations
5. **Version Control**: Track all code and configurations

### Performance Optimization

1. **Partition Data**: Use appropriate partitioning strategies
2. **Incremental Processing**: Only process new/changed data
3. **Caching**: Materialize intermediate results
4. **Query Optimization**: Use EXPLAIN to analyze queries
5. **Indexing**: Create strategic indexes for analytics

### Data Governance

1. **Data Catalog**: Maintain inventory of all data assets
2. **Documentation**: Document all transformations and calculations
3. **Access Control**: Implement role-based access
4. **Lineage Tracking**: Understand data dependencies
5. **Quality SLAs**: Define and monitor data quality expectations
