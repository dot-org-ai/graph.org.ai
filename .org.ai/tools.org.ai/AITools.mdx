# AI Tools

Model inference, embeddings, fine-tuning, evaluation, and AI platform tools for building and deploying AI applications.

## Overview

AI tools enable developers to build intelligent applications without training models from scratch. They provide access to state-of-the-art language models, tools for managing AI workflows, and platforms for evaluating and improving AI systems.

## Language Models & APIs

### Claude (Anthropic)

Advanced language model with strong reasoning and safety:

```typescript
import Anthropic from '@anthropic-ai/sdk'

const client = new Anthropic()

const message = await client.messages.create({
  model: "claude-3-5-sonnet-20241022",
  max_tokens: 1024,
  messages: [
    {
      role: "user",
      content: "Explain quantum computing in simple terms"
    }
  ]
})

console.log(message.content[0].type === 'text' && message.content[0].text)
```

**Model Variants:**

- **Claude 3.5 Sonnet**: Fastest, best for most tasks
- **Claude 3 Opus**: Most capable, for complex reasoning
- **Claude Haiku**: Smallest, for low-latency applications

**Key Features:**
- 200K token context window
- Tool/function calling
- Vision capabilities
- Batch processing API
- Long context support

### Vector Databases

```python
from pinecone import Pinecone

# Initialize Pinecone
pc = Pinecone(api_key="your-api-key")
index = pc.Index("documents")

# Store embeddings
vectors = [
    {
        "id": "doc1",
        "values": [0.1, 0.2, 0.3, ...],

        "id": "doc2",

)
```

## RAG (Retrieval Augmented Generation)

### LlamaIndex

Framework for building RAG applications:

```python
from llama_index.core import VectorStoreIndex, SimpleDirectoryReader

# Load documents
documents = SimpleDirectoryReader("docs").load_data()

# Create index
index = VectorStoreIndex.from_documents(documents)

# Query
query_engine = index.as_query_engine()
response = query_engine.query(
    "What are the main features of this product?"
)
print(response)
```

### LangChain RAG

Building retrieval-augmented generation chains:

```python
from langchain.chat_models import ChatOpenAI
from langchain.embeddings import OpenAIEmbeddings
from langchain.vectorstores import Pinecone
from langchain.chains import RetrievalQA

# Setup components
embeddings = OpenAIEmbeddings()
vectorstore = Pinecone.from_existing_index(
    index_name="documents",
    embedding=embeddings
)

# Create RAG chain
qa = RetrievalQA.from_chain_type(
    llm=ChatOpenAI(model="gpt-4"),
    chain_type="stuff",
    retriever=vectorstore.as_retriever(k=3)
)

# Query
response = qa.run("What are the pricing plans?")
```

## Fine-Tuning & Training

### OpenAI Fine-Tuning

```bash
# Prepare training data (JSONL format)
# Each line: {"messages": [{"role": "system", "content": "..."}, {"role": "user", "content": "..."}, {"role": "assistant", "content": "..."}]}

# Upload file
openai api files.create -f training_data.jsonl -p fine-tune

# Create fine-tuning job
openai api fine_tunes.create \
  -t <FILE_ID> \
  --model gpt-3.5-turbo

# Use fine-tuned model
openai api completions.create \
  -m ft-<FINE_TUNE_MODEL_ID> \
  -p "User query"
```

## Prompt Engineering

### Basic Techniques

**Few-Shot Learning:**
```
Answer the question with one of the provided options.

Examples:
Q: Is a tomato a fruit or vegetable?
A: Fruit

Q: Is a carrot a fruit or vegetable?
A: Vegetable

Q: Is a cucumber a fruit or vegetable?
A: Fruit
```

**Chain of Thought:**
```
Let's solve this step by step:

Problem: If Mary has 3 apples and buys 5 more, but gives 2 to John, how many does she have?

Step 1: Mary starts with 3 apples
Step 2: She buys 5 more, so 3 + 5 = 8 apples
Step 3: She gives 2 to John, so 8 - 2 = 6 apples
Answer: Mary has 6 apples
```

**Role-Based Prompting:**
```
You are an expert Python developer with 10 years of experience.
Explain how to optimize database queries for a junior developer.
```

### Prompt Templates

```typescript
interface PromptTemplate {
  template: string
  variables: string[]
}

const analyzeCodeTemplate: PromptTemplate = {
  template: `
Analyze the following code for:
- Performance issues
- Security vulnerabilities
- Code quality improvements

Code:
{code}

Analysis:
  `,
  variables: ["code"]
}

function formatPrompt(template: PromptTemplate, values: Record<string, string>) {
  let result = template.template
  template.variables.forEach(variable => {
    result = result.replace(`{${variable}}`, values[variable])
  })
  return result
}
```

## Best Practices

### Prompt Design

1. **Be Specific**: Clear, detailed instructions produce better results
2. **Provide Context**: Give relevant background information
3. **Show Examples**: Few-shot learning improves consistency
4. **Specify Format**: Define expected output format
5. **Iterate**: Test and refine prompts for quality

### Cost Optimization

1. **Use Caching**: Cache repeated prompts
2. **Batch Processing**: Process multiple items together
3. **Model Selection**: Choose appropriate model size
4. **Token Counting**: Optimize prompt lengths
5. **Monitor Usage**: Track API calls and costs

### Safety & Ethics

1. **Input Validation**: Sanitize user inputs
2. **Output Filtering**: Filter harmful content
3. **Rate Limiting**: Prevent abuse
4. **Audit Logging**: Track API usage
5. **Bias Awareness**: Monitor model outputs for bias
