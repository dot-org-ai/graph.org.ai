# defense.org.ai

[![License: CC BY-SA 4.0](https://img.shields.io/badge/License-CC%20BY--SA%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by-sa/4.0/)

Comprehensive defense industry ontology covering weapons systems, military equipment, defense contracting, technology, services, intelligence systems, and space defense capabilities.

## Overview

This repository contains MDX documentation for defense.org.ai, part of the .org.ai ontology ecosystem. The Defense domain provides detailed information about the global defense and military industry, including procurement processes, equipment specifications, technology systems, and service ecosystems that support military operations.

**Parent**: [industries.org.ai](https://industries.org.ai)

- **3364** - Aerospace Product and Parts Manufacturing

## NAICS Code Alignment

### NAICS 3364 - Aerospace Product and Parts Manufacturing

This classification covers establishments primarily engaged in manufacturing or assembling complete aerospace products (such as aircraft, missiles, helicopters, and spacecraft) or manufacturing aerospace components and parts. The category includes:

**33641 - Aerospace Product and Parts Manufacturing (6-digit level)**
- Aircraft manufacturing (commercial and military)
- Aerospace engine and engine parts manufacturing
- Aerospace propeller and propeller parts manufacturing
- Guided missile and space vehicle manufacturing
- Guided missile and space vehicle parts and auxiliary equipment manufacturing
- Aircraft parts and auxiliary equipment manufacturing
- Aerospace structural components and missile parts manufacturing

**Defense Industry Components within NAICS 3364:**
- Lockheed Martin Corporation - Fighter aircraft, missiles, space systems
- Boeing Defense Space & Security - Aircraft systems, missiles, satellites
- Northrop Grumman - Aircraft systems, electronic warfare, missiles
- Raytheon Technologies - Missiles, sensors, propulsion systems
- General Dynamics - Combat vehicles, submarines, munitions
- Huntington Ingalls Industries - Naval vessels and submarines
- Booz Allen Hamilton - Consulting and professional services

### NAICS 9281 - National Security

This classification covers activities of national government agencies primarily engaged in national security activities. Includes defense, armed forces, military equipment operations, and related activities.

**9281 Coverage:**
- Armed Forces operations
- Military intelligence operations
- Military logistics and supply
- Military training and education
- Defense system operations
- Strategic planning and policy

## Usage Examples

### Import as NPM Package

```typescript
import { DefenseContractor, MilitaryEquipment, DefenseService } from '@org.ai/defense'
```

### Reference in MDX

```mdx
---
$type: DefenseContractor
name: Lockheed Martin
sector: Aerospace & Defense
products: [Fighters, Missiles, Satellites]
---

# Lockheed Martin

<ContractorOverview contractor={contractor} />

See related: [DefenseTechnology](./DefenseTechnology.mdx)
```

### Query Defense Industry Data

```typescript
// Get all defense contractors
const contractors = await $.db.find({
  $context: 'https://defense.industries.org.ai',
  $type: 'DefenseContractor'
})

// Find weapons systems by category
const missiles = await $.db.find({
  $context: 'https://defense.industries.org.ai/MilitaryEquipment',
  category: 'Missiles'
})

// Search defense services
const services = await $.db.search('maintenance repair services', {
  $context: 'https://defense.industries.org.ai/DefenseServices'
})
```
