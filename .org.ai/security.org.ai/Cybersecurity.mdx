# Cybersecurity

Cybersecurity encompasses the practices, technologies, and processes designed to protect networks, devices, programs, and data from attack, damage, or unauthorized access. It involves defending digital assets against threats ranging from nation-state attacks to ransomware, phishing, and insider threats.

## Overview

Modern cybersecurity is a multi-layered discipline that combines preventive controls, detection capabilities, incident response procedures, and continuous improvement through threat intelligence and security analytics. Organizations must defend against increasingly sophisticated attackers while enabling business operations and digital transformation.

## Core Service Areas

### Security Operations Center (SOC)

A SOC is a centralized unit that deals with security issues on an organizational and technical level:

**SOC Functions**:
- **24/7/365 Monitoring**: Continuous surveillance of security events and alerts
- **Threat Detection**: Identifying potential security incidents through SIEM, EDR, and other tools
- **Incident Triage**: Prioritizing alerts based on severity and business impact
- **Incident Response**: Containing and remediating security incidents
- **Threat Hunting**: Proactive search for indicators of compromise
- **Security Analytics**: Analysis of security data to identify patterns and trends
- **Forensic Investigation**: Deep-dive analysis of security incidents

**SOC Tiers**:
- **Tier 1 - Alert Analysts**: First-line triage and initial investigation
- **Tier 2 - Incident Responders**: Detailed analysis and containment
- **Tier 3 - Threat Hunters**: Proactive threat hunting and advanced analysis
- **SOC Manager**: Oversight, metrics, and continuous improvement

**SOC Technologies**:
- Security Information and Event Management (SIEM)
- Endpoint Detection and Response (EDR)
- Network Detection and Response (NDR)
- Security Orchestration, Automation, and Response (SOAR)
- Threat intelligence platforms
- Log management and analytics
- Network traffic analysis
- User and Entity Behavior Analytics (UEBA)

### Vulnerability Management

Continuous identification, evaluation, treatment, and reporting of security vulnerabilities:

**Vulnerability Assessment Process**:

1. **Asset Discovery**: Identify all IT assets and applications
2. **Vulnerability Scanning**: Automated scanning for known vulnerabilities
3. **Risk Assessment**: Evaluate vulnerability severity and business impact
4. **Prioritization**: Rank vulnerabilities based on risk scores
5. **Remediation**: Patching, configuration changes, or compensating controls
6. **Verification**: Confirm vulnerabilities have been addressed
7. **Reporting**: Metrics and progress tracking

**Scanning Technologies**:
- Network vulnerability scanners (Nessus, Qualys, Rapid7)
- Web application scanners (Burp Suite, Acunetix)
- Container vulnerability scanners
- Cloud security posture management (CSPM)
- Software composition analysis (SCA)
- Static and dynamic application security testing (SAST/DAST)

**Vulnerability Prioritization**:
- CVSS (Common Vulnerability Scoring System)
- EPSS (Exploit Prediction Scoring System)
- Asset criticality
- Threat intelligence context
- Compensating controls
- Business impact analysis

## Cybersecurity Domains

### Network Security

Protecting network infrastructure and traffic:

- **Firewalls**: Next-generation firewalls (NGFW) with application awareness
- **VPN**: Virtual Private Networks for secure remote access
- **Network Segmentation**: Micro-segmentation and zero trust networks
- **DDoS Protection**: Distributed denial of service mitigation
- **DNS Security**: DNS filtering and threat protection
- **Email Security**: Anti-spam, anti-phishing, malware scanning
- **Web Filtering**: URL filtering and content inspection

### Application Security

Securing applications throughout the development lifecycle:

- **Secure Software Development Lifecycle (SSDLC)**
- **DevSecOps**: Integration of security into DevOps practices
- **Security Testing**: SAST, DAST, IAST, RASP
- **API Security**: OAuth, API gateways, rate limiting
- **Container Security**: Image scanning, runtime protection
- **Secrets Management**: Secure storage of credentials and keys
- **Software Bill of Materials (SBOM)**

### Cloud Security

Securing cloud environments and workloads:

- **Identity and Access Management**: Cloud IAM policies
- **Cloud Posture Management**: Configuration compliance
- **Cloud Workload Protection**: VM, container, and serverless security
- **Data Encryption**: At-rest and in-transit encryption
- **Cloud Access Security Broker (CASB)**: SaaS security
- **Multi-cloud Security**: Unified security across providers
- **Infrastructure as Code (IaC) Security**: Terraform, CloudFormation scanning

### Data Security

Protecting sensitive data throughout its lifecycle:

- **Data Classification**: Identifying and labeling sensitive data
- **Encryption**: At-rest, in-transit, and in-use encryption
- **Data Loss Prevention (DLP)**: Preventing unauthorized data exfiltration
- **Database Security**: Access controls, encryption, monitoring
- **Backup and Recovery**: Secure backup and disaster recovery
- **Data Masking and Tokenization**: Protecting sensitive data in non-production
- **Key Management**: Cryptographic key lifecycle management

### Endpoint Security

Protecting end-user devices:

- **Endpoint Detection and Response (EDR)**: Advanced threat detection
- **Antivirus/Anti-malware**: Signature and behavior-based protection
- **Mobile Device Management (MDM)**: Securing mobile devices
- **Patch Management**: Automated update deployment
- **Application Control**: Whitelisting and blacklisting
- **Disk Encryption**: Full-disk encryption (BitLocker, FileVault)
- **USB Control**: Removable media protection

## Attack Types and Defenses

**Phishing and Social Engineering**:
- Email phishing attacks
- Spear phishing (targeted attacks)
- Business Email Compromise (BEC)
- Vishing (voice phishing)
- Smishing (SMS phishing)
- Watering hole attacks

**Malware**:
- Ransomware
- Trojans and backdoors
- Spyware and keyloggers
- Rootkits
- Botnets
- Cryptominers
- Worms and viruses

**Web-Based Attacks**:
- SQL injection
- Cross-Site Scripting (XSS)
- Cross-Site Request Forgery (CSRF)
- Server-Side Request Forgery (SSRF)
- XML External Entity (XXE)
- Insecure deserialization

**Network Attacks**:
- Man-in-the-Middle (MitM)

**Credential Attacks**:
- Password spraying
- Brute force attacks

- Pass-the-hash

**Advanced Persistent Threats (APT)**:
- Multi-stage attacks

- Lateral movement

- Living-off-the-land techniques
- Zero-day exploits

## Frameworks and Standards

### NIST Cybersecurity Framework

Five core functions: Identify, Protect, Detect, Respond, Recover (detailed in README.md)

### CIS Controls

20 prioritized cybersecurity best practices:
- **Basic Controls (1-6)**: Inventory, configuration, vulnerability management
- **Foundational Controls (7-16)**: Email security, malware defense, data recovery
- **Organizational Controls (17-20)**: Incident response, penetration testing, security awareness

### ISO/IEC 27001

International standard for Information Security Management Systems (ISMS)

### MITRE ATT&CK Framework

Knowledge base of adversary tactics and techniques based on real-world observations:
- 14 tactics (Initial Access, Execution, Persistence, etc.)
- 100+ techniques and sub-techniques
- Platform-specific matrices (Windows, Linux, macOS, cloud)
- Used for threat intelligence, detection, and red teaming
