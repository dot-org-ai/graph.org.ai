# 54 - Professional, Scientific, and Technical Services

Industries where human capital is the major input and establishments sell expertise and services.

## Description

This sector comprises establishments that specialize in performing professional, scientific, and technical activities for others. These activities require a high degree of expertise and training. The establishments in this sector specialize according to expertise and provide these services to clients in a variety of industries and, in some cases, to households.

### 541511 Custom Computer Programming Services

Establishments primarily engaged in writing, modifying, testing, and supporting software to meet the needs of a particular customer.

**Illustrative Examples:**
- Custom computer programming services
- Computer code writers, custom
- Software preparation services, custom
- Computer software development, custom (for operating system)
- Computer software programming services, custom

### 541512 Computer Systems Design Services

Establishments primarily engaged in planning and designing computer systems that integrate hardware, software, and communication technologies.

**Illustrative Examples:**
- Computer systems integration design consulting services
- Information management system design consulting services
- Local area network (LAN) computer systems integration design services
- Office automation (integrated hardware/software) design services
