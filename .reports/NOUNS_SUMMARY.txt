================================================================================
FILE STRUCTURE
================================================================================

Columns in Nouns.tsv:
  1. id          - Unique identifier for the noun
  2. type        - Always "Noun" (for ontology consistency)
  3. name        - Human-readable display name
  4. description - Detailed description of the noun
  5. source      - Origin taxonomy (schema.org, onet.org.ai, etc.)
  6. properties  - Key properties/attributes specific to this type
  7. parent      - Parent class in hierarchy (empty for root classes)
